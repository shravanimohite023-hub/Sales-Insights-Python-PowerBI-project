# End-to-End Sales Analytics Project (Python + Power BI)

## 📌 Project Overview
This project delivers an end-to-end sales analytics solution, combining the statistical power of **Python** with the advanced visualization capabilities of **Power BI**. The objective is to clean raw transactional data, perform Exploratory Data Analysis (EDA) to uncover business insights, and build a premium, highly interactive **Dark-Themed Executive Dashboard** for tracking corporate performance.

---

## 🛠️ Tech Stack & Tools Used
* **Data Cleaning & EDA:** Python (Pandas, NumPy, Matplotlib, Seaborn)
* **Data Visualization:** Power BI Desktop
* **Theme & UI:** Optimized Dark/Neon Business Intelligence Interface

---

## 📊 Business Key Performance Indicators (KPIs) Captured
The Power BI dashboard features executive-level KPI cards aligned perfectly with the deep dark theme for high scannability:
1. **Total Revenue:** Evaluates the aggregate financial health and gross sales generation.
2. **Total Profit Margin:** Monitors actual bottom-line profitability across orders.
3. **Total Quantity Sold:** Tracks operational sales volume and product movement.
4. **Unique Customer Count:** Measures market penetration and customer acquisition.

---

## ⚙️ Project Workflow & Implementation

### Phase 1: Python Data Engineering & EDA
* Cleaned raw transactional records by handling missing entities, removing duplicates, and fixing data types.
* Performed exploratory analysis to determine product performance, revenue distribution, and customer purchase frequencies.
* Exported the refined, structured dataset (`sales_clean.csv`) to serve as a reliable source of truth.

### Phase 2: Power BI Premium Dashboard Design
* Implemented a custom dark purple/navy-mix canvas theme to maximize visual contrast.
* Transformed traditional visualization grids by rendering charts with transparent effects, clean borders, and highly readable light-gray typography.
* Leveraged dynamic user filters (Slicers) and structured chart interaction to drill down into segments, revenue over time, and product quantities.

---

## 🔑 Key Insights Discovered
* **Top Revenue Generator:** Successfully identified high-performing product categories (e.g., Copy Paper segments) that dominate business revenue.
* **Customer Distribution:** Mapped out purchase trends over specific timelines, enabling targeted marketing campaigns for distinct segments.

---

## 🚀 How to Run this Project
1. **Python Script:** Open the `.ipynb` notebook file inside the repository to view the full data preparation and EDA pipeline.
2. **Power BI Dashboard:** Download the `.pbix` file and open it in Power BI Desktop to interact with the live report.
